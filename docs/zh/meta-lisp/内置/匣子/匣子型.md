# 类型

```meta-lisp
类型型
```

# 描述

Box 类型构造器。内部表示为 `(列表型 E)`。

# 定义

```meta-lisp
(定义黑盒类型 (匣子型 E) (列表型 E)
  (作匣子 (-> (匣子型 E)))
  (匣子为空 (-> (匣子型 E) 真假型))
  (匣子存 (-> E (匣子型 E) (匣子型 E)))
  (匣子取或有 (-> (匣子型 E) (或有型 E))))
```

# 自动生成

```meta-lisp
(声明 作匣子 (泛型 (甲) (-> (匣子型 甲))))
(声明 匣子为空 (泛型 (甲) (-> (匣子型 甲) 真假型)))
(声明 匣子存 (泛型 (甲) (-> 甲 (匣子型 甲) (匣子型 甲))))
(声明 匣子取或有 (泛型 (甲) (-> (匣子型 甲) (或有型 甲))))
(声明 匣子取 (泛型 (甲) (-> (匣子型 甲) 甲)))
```

# 例子

```meta-lisp
(定义 box (作匣子))
(匣子为空 box)    ;; => 真
(匣子存 42 box)
(匣子为空 box)    ;; => 假
(匣子取或有 box) ;; => (有 42)
(匣子取 box)       ;; => 42
```

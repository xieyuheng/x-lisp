---
title: 列表右折叠索引
---

# 类型

```meta-lisp
(泛型 (甲 乙) (-> (-> 整数型 甲 乙 乙) 乙 (列表型 甲) 乙))
```

# 描述

带索引的右折叠。回调依次接收 index、当前元素和已折叠值。

# 例子

```meta-lisp
(列表右折叠索引 (函 (i x folded) (添 (作序对 i x) folded)) [] ['a 'b 'c])
;; => [(作序对 0 'a) (作序对 1 'b) (作序对 2 'c)]

(列表右折叠索引 (函 (i x folded) (整数加 (整数乘 i x) folded)) 0 [10 20 30])
;; => 80
```

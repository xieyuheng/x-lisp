---
title: 列表映射拼接
---

# 类型

```meta-lisp
(泛型 (甲 乙) (-> (-> 甲 (列表型 乙)) (列表型 甲) (列表型 乙)))
```

# 描述

对列表中的每个元素应用函数 `f`，将结果列表扁平化一层。等价于 `(列表拼接 (列表映射 f xs))`。

# 例子

```meta-lisp
(列表映射拼接 (函 (x) [x (整数加 x 1)]) [1 3])  ;; => [1 2 3 4]
(列表映射拼接 (函 (x) []) [1 2 3])           ;; => []
(列表映射拼接 列表反转 [[1 2 3] [4 5 6]])    ;; => [3 2 1 6 5 4]
```

```meta-lisp
类型型
```

# 描述

带位置的 S 表达式类型。表示解析后的 S 表达式及其源码位置。

# 定义

```meta-lisp
(定义枚举 符号算式型
  (符号符号算式  (content 符号型)               (location 源位置型))
  (标签符号算式 (content 标签型)             (location 源位置型))
  (文本符号算式 (content 文本型)             (location 源位置型))
  (整数符号算式   (content 整数型)               (location 源位置型))
  (浮点符号算式   (content 浮点型)               (location 源位置型))
  (列表符号算式   (elements (列表型 符号算式型))
                  (location 源位置型)))
```

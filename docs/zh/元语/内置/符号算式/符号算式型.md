# 类型

```meta-lisp
类型型
```

# 描述

带位置的 S 表达式类型。表示解析后的 S 表达式及其源码位置。

# 定义

```meta-lisp
(定义枚举 符号算式型
  (符号符号算式  (内容 符号型)           (位置 源码位置型))
  (标签符号算式 (内容 标签型)           (位置 源码位置型))
  (文本符号算式 (内容 文本型)           (位置 源码位置型))
  (整数符号算式   (内容 整数型)           (位置 源码位置型))
  (浮点符号算式   (内容 浮点型)           (位置 源码位置型))
  (列表符号算式   (元素 (列表型 符号算式型))
                  (位置 源码位置型)))
```

# 类型

```meta-lisp
类型型
```

# 描述

源码位置类型。包含索引、行号和列号。

# 定义

```meta-lisp
(定义结构 源坐标型
  (index 整数型)
  (row 整数型)
  (column 整数型))
```

# 自动生成

```meta-lisp
(声明 作源坐标 (-> 整数型 整数型 整数型 源坐标型))
(声明 为源坐标     (-> 源坐标型 真假型))
(声明 源坐标-index  (-> 源坐标型 整数型))
(声明 源坐标-row    (-> 源坐标型 整数型))
(声明 源坐标-column (-> 源坐标型 整数型))
```

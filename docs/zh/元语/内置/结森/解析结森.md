---
title: 解析结森
---

# 类型

```meta-lisp
(-> 字符串型 结森型)
```

# 描述

将 JSON 字符串解析为 `结森型` 值。

# 例子

```meta-lisp
(解析结森 "null")            ;; => (结森-null)
(解析结森 "true")            ;; => (结森-bool 真)
(解析结森 "42")              ;; => (结森-number 42.0)
(解析结森 "\"hello\"")       ;; => (结森-string "hello")
(解析结森 "[1, 2, 3]")       ;; => (结森-array [(结森-number 1.0) ...])
(解析结森 "{\"x\": 1}")      ;; => (结森-object (@散列 "x" (结森-number 1.0)))
```

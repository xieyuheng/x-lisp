# 描述

JSON 值类型。表示解析后的 JSON 值。

# 定义

```meta-lisp
(定义枚举 结森型
  (结森-null)
  (结森-bool    (value 真假型))
  (结森-number  (value 浮点型))
  (结森-string  (value 文本型))
  (结森-array   (elements (列表型 结森型)))
  (结森-object  (entries (散列型 文本型 结森型))))
```

# 类型

```meta-lisp
类型型
```

# 描述

Box 类型构造器。内部表示为 `(列表型 E)`。

# 定义

```meta-lisp
(定义黑盒类型 (匣子型 E) (列表型 E)
  (作匣子 (-> (匣子型 E)))
  (匣子空乎 (-> (匣子型 E) 布尔型))
  (匣子置之 (-> E (匣子型 E) (匣子型 E)))
  (匣子取或有 (-> (匣子型 E) (或有型 E))))
```

# 例子

```meta-lisp
(定义 box (作匣子))
(匣子空乎 box)    ;; => 真
(匣子置之 42 box)
(匣子空乎 box)    ;; => 假
(匣子取或有 box) ;; => (有 42)
(匣子取 box)       ;; => 42
```

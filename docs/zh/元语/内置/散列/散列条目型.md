title: 散列条目型

# 类型

```meta-lisp
类型型
```

# 描述

哈希表条目类型构造器。`(散列条目型 K V)` 表示一个键类型为 `K`、值类型为 `V` 的键值对条目。

# 定义

```meta-lisp
(定义结构 (散列条目型 K V)
  (key K)
  (value V))
```

# 自动生成

```meta-lisp
(声明 作散列条目 (多态 (键 值) (-> 键 值 (散列条目型 键 值))))
(声明 散列条目键   (多态 (键 值) (-> (散列条目型 键 值) 键)))
(声明 散列条目值 (多态 (键 值) (-> (散列条目型 键 值) 值)))
```

# 例子

```meta-lisp
(令 ((e (作散列条目 "a" 1)))
  (散列条目键 e))   ;; => "a"
```

---
title: 散列映射条目
---

# 类型

```meta-lisp
(多态 (键甲 值甲 键乙 值乙)
  (-> (-> (散列条目型 键甲 值甲) (散列条目型 键乙 值乙))
      (散列型 键甲 值甲)
      (散列型 键乙 值乙)))
```

# 描述

对每个 entry 应用函数。

# 例子

```meta-lisp
(散列映射条目
  (函 (e)
    (作散列条目
      (整数加 1 (散列条目键 e))
      (整数加 1 (散列条目值 e))))
  (@散列 1 2 3 4))
;; => (@散列 2 3 4 5)
```

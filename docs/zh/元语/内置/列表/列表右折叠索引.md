---
title: 列表右折叠索引
---

# 类型

```meta-lisp
(多态 (E R) (-> (-> 整数型 E R R) R (列表型 E) R))
```

# 描述

带索引的右折叠。回调依次接收 index、当前元素和已折叠值。

# 例子

```meta-lisp
(列表右折叠索引 (函 (i x folded) (添 (作二元组 i x) folded)) [] ['a 'b 'c])
;; => [(作二元组 0 'a) (作二元组 1 'b) (作二元组 2 'c)]

(列表右折叠索引 (函 (i x folded) (整数加 (整数乘 i x) folded)) 0 [10 20 30])
;; => 80
```

---
title: 列表排序
---

# 类型

```meta-lisp
(多态 (E) (-> (-> E E 整数型) (列表型 E) (列表型 E)))
```

# 描述

使用比较函数对列表原地排序。返回原列表。

# 例子

```meta-lisp
;; int
(列表排序 整数升序比较 [3 1 2])   ;; => [1 2 3]
(列表排序 整数降序比较 [3 1 2])  ;; => [3 2 1]

;; float
(列表排序 浮点升序比较 [3.0 1.0 2.0])   ;; => [1.0 2.0 3.0]
(列表排序 浮点降序比较 [3.0 1.0 2.0])  ;; => [3.0 2.0 1.0]

;; string
(列表排序 文本字典序比较 ["c" "a" "b"])     ;; => ["a" "b" "c"]
```

---
title: 列表复制排序
---

# 类型

```meta-lisp
(多态 (甲) (-> (-> 甲 甲 整数型) (列表型 甲) (列表型 甲)))
```

# 描述

使用比较函数排序列表的副本。不修改原列表。

# 例子

```meta-lisp
;; int
(列表复制排序 整数升序比较 [3 1 2])    ;; => [1 2 3]
(列表复制排序 整数降序比较 [3 1 2])   ;; => [3 2 1]

;; float
(列表复制排序 浮点升序比较 [3.0 1.0 2.0])   ;; => [1.0 2.0 3.0]
(列表复制排序 浮点降序比较 [3.0 1.0 2.0])  ;; => [3.0 2.0 1.0]

;; text
(列表复制排序 文本字典序比较 ["c" "a" "b"])     ;; => ["a" "b" "c"]
```

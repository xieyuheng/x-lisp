---
title: 列表展平映射
---

# 类型

```meta-lisp
(多态 (A B) (-> (-> A (列表型 B)) (列表型 A) (列表型 B)))
```

# 描述

对列表中的每个元素应用函数 `f`，将结果列表扁平化一层。等价于 `(列表连接 (列表映射 f xs))`。

# 例子

```meta-lisp
(列表展平映射 (函 (x) [x (整数加 x 1)]) [1 3])  ;; => [1 2 3 4]
(列表展平映射 (函 (x) []) [1 2 3])           ;; => []
(列表展平映射 列表反转 [[1 2 3] [4 5 6]])    ;; => [3 2 1 6 5 4]
```

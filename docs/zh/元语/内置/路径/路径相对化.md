---
title: 路径相对
---

# 类型

```meta-lisp
(-> 文本型 文本型 文本型)
```

# 描述

返回 `to` 相对于 `from` 的相对路径。

注意：`from` 和 `to` 必须同为绝对路径或同为相对路径，不能混用。

# 例子

绝对路径：

```meta-lisp
(路径相对 "/a/b/c" "/a/b/d/e")    ;; => "../d/e"
(路径相对 "/a/b/c" "/a/b/c/d")    ;; => "d"
(路径相对 "/app/config" "/app")   ;; => ".."
```

相对路径：

```meta-lisp
(路径相对 "a/b/c" "a/b/d/e")      ;; => "../d/e"
(路径相对 "a/b/c" "a/b/c/d")      ;; => "d"
(路径相对 "." "src")              ;; => "src"
```

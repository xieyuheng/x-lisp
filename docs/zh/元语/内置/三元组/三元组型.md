# 类型

```meta-lisp
类型型
```

# 描述

三元组类型构造器。`(三元组型 A B C)` 表示一个包含类型 `A`、`B` 和 `C` 三个值的组。

# 定义

```meta-lisp
(定义结构 (三元组型 A B C)
  (第一 A)
  (第二 B)
  (第三 C))
```

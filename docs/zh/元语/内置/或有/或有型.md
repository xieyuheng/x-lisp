# 类型

```meta-lisp
类型型
```

# 描述

可选值类型构造器。`(或有型 A)` 表示可能存在也可能不存在类型为 `A` 的值。

# 定义

```meta-lisp
(定义枚举 (或有型 A)
  (有 (值 A))
  (无))
```

# 自动生成

```meta-lisp

(声明 有乎 (多态 (A) (-> (或有型 A) 布尔型)))
(声明 有值 (多态 (A) (-> (或有型 A) A)))
(声明 有置值之 (多态 (A) (-> A (或有型 A) (或有型 A))))

(声明 无 (多态 (A) (-> (或有型 A))))
(声明 无乎 (多态 (A) (-> (或有型 A) 布尔型)))
```

# 例子

```meta-lisp
(定义 x (有 42))
(有乎 x)          ;; => 真
(无乎 x)       ;; => 假
(有值 x)     ;; => 42
```

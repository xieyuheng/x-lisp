# 类型

```meta-lisp
类型型
```

# 描述

可选值类型构造器。`(或有型 A)` 表示可能存在也可能不存在类型为 `A` 的值。

# 定义

```meta-lisp
(定义枚举 (或有型 A)
  (有 (值 A))
  (无))
```

# 例子

```meta-lisp
(定义 x (有 42))
(为有 x)          ;; => 真
(为无 x)       ;; => 假
(有值 x)     ;; => 42
```

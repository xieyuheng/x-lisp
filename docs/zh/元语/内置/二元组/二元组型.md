# 类型

```meta-lisp
类型型
```

# 描述

二元组类型构造器。`(二元组型 A B)` 表示一个包含类型 `A` 和 `B` 两个值的对。

# 定义

```meta-lisp
(定义结构 (二元组型 A B)
  (第一 A)
  (第二 B))
```

# 前言

meta-lisp 使用**符号表达式**（S-expression）语法。

- 模块顶层由**语句**（statement）组成。
- 语句内由**表达式**（expression）组成。

下面分组介绍 meta-lisp 的所有语法。

# 注释

## 行注释

注释以 `;` 开头，直到行尾。

在写行注释的时候 lisp 程序员通常写两个 `;;`。

```meta-lisp
;; 这是一条注释
(定义 x 42) ;; 行尾注释
```

## (@comment)

```meta-lisp
(@注释 <sexp> ...)
```

`(@注释)` 在编译时被忽略，其表达式求值为 `空`。

```meta-lisp
(@注释 (函 (<parameter> ...)
            <body>))
(@注释 (若 <condition> <consequent> <alternative>))
(@注释 foo bar)
```

`@注释` 被解析器识别为语法关键字，其内容是字面 S 表达式，不会被求值。

# 字面量

## 原子

整数由数字组成，可选负号。

```meta-lisp
42
-1
0
```

浮点数带小数点。

```meta-lisp
3.14
-2.5
```

文本用双引号包裹。

```meta-lisp
"hello"
""
```

符号用单引号开头，后面跟名字。

```meta-lisp
'foo
'bar
```

关键字用冒号开头。

```meta-lisp
:key
:name
```

真假值用 `真` 和 `假`，它们不是字面量，而是绑定了真假值的变量。

空值用 `空`，它也不是字面量，而是绑定了空值的变量。

## (@list)

```meta-lisp
[<exp> ...]
(@列表 <exp> ...)
```

创建列表。

```meta-lisp
[1 2 3]
["a" "b" "c"]
```

方括号 `[...]` 是 `(@列表 ...)` 的语法糖。

上面的例子等价于：

```meta-lisp
(@列表 1 2 3)
(@列表 "a" "b" "c")
```

增加 `@` 前缀，是为了避免占用 `list` 这个变量名。

## (@集合)

```meta-lisp
(@集合 <exp> ...)
```

创建集合。

```meta-lisp
(@集合 1 2 3)
```

## (@hash)

```meta-lisp
(@散列 <key> <value> ...)
```

创建哈希表。

```meta-lisp
(@散列 :a 1 :b 2)
(@散列 "a" 1 "b" 2)
```

## (@string)

```meta-lisp
(@文本 <exp> ...)
```

将多个文本表达式拼接成一个文本。

```meta-lisp
(@文本 "hello" " " "world")
(@文本 "(" x ")")
(@文本)
```

上面的例子等价于：

```meta-lisp
(文本连接 ["hello" " " "world"])
(文本连接 ["(" x ")"])
(文本连接 [])
```

## (@quote)

```meta-lisp
'<sexp>
(@引用 <sexp>)
```

创建符号或原子列表。

```meta-lisp
'(a b c)         ;; => ['a 'b 'c]
'(1 2 3)         ;; => [1 2 3]
```

等价于：

```meta-lisp
(@引用 (a b c))  ;; => ['a 'b 'c]
(@引用 (1 2 3))  ;; => [1 2 3]
```

## (@sexp)

```meta-lisp
(@符号算式 <sexp>)
```

将 s-expression 转化为 `符号算式型` 类型的值，保留每个子节点的源代码位置信息。

`符号算式型` 类型的定义：

```meta-lisp
(定义枚举 符号算式型
  (symbol-sexp (content 符号型) (location 源位置型))
  (keyword-sexp (content 关键字型) (location 源位置型))
  (string-sexp (content 文本型) (location 源位置型))
  (int-sexp (content 整数型) (location 源位置型))
  (float-sexp (content 浮点型) (location 源位置型))
  (list-sexp (elements (列表型 符号算式型)) (location 源位置型)))
```

使用示例：

```meta-lisp
(@符号算式 foo)           ;; => (symbol-sexp 'foo <location>)
(@符号算式 (a b c))       ;; => (list-sexp
                      ;;      (list (symbol-sexp 'a) (symbol-sexp 'b) (symbol-sexp 'c))
                      ;;      <location>)
```

# 变量

## (define)

```meta-lisp
(定义 <name> <exp>)
```

定义模块级变量。

```meta-lisp
(定义 answer 42)
(定义 greeting "hello")
```

## 变量

变量引用一个已绑定的名字。

名字由字母、数字和 `-` `?` `!` 等字符组成。

```meta-lisp
x
factorial
列表长度
列表为空
```

## 限定变量

`<module-name>/<name>` 引用其他模块中的名字。

```meta-lisp
内置/列表长度
内置/列表为空
```

限定名不需要先 `(导入)`，可以直接使用。
`(导入)` 是专门用来取消 `<module-name>` 前缀的。


# 函数

## 函数作用

```meta-lisp
(<target> <arg> ...)
```

函数作用是最重要的语法。

如果符号表达式的第一个位置不是语法关键词，就被认为是函数作用。

第一个位置是函数，其余是参数。

先求值函数位置的表达式，
然后求值所有参数位置的表达式，
然后进行函数作用。

```meta-lisp
(整数加 1 2)
(打印行 "hello")
((函 (x) x) 1)
```

当函数作用的参数个数不足时，会形成部分作用（通过**柯里化**实现）。

```meta-lisp
((整数加 1) 2)
```

等价于：

```meta-lisp
(整数加 1 2)
```

并且 `(整数加 1)` 可以作为值传递给函数，或者作为结果返回。

```meta-lisp
(定义 add1
  (整数加 1))
```

等价于：

```meta-lisp
(定义 (add1 x)
  (整数加 1 x))
```

## (lambda)

```meta-lisp
(函 (<parameter> ...)
  <body>)
```

创建匿名函数。

`(<parameter> ...)` 是形式参数列表，
`<body>` 是一个或多个表达式。
当函数被作用时，实际参数被绑定到形式参数，然后求值 `<body>`。

```meta-lisp
(函 (x) (整数加 x 1))
((函 (x) (整数加 x 1)) 2)  ;; => 3
```

多个参数：

```meta-lisp
(函 (x y)
  (整数加 x y))
```

等价于：

```meta-lisp
(函 (x)
  (函 (y)
    (整数加 x y)))
```

## (define)

```meta-lisp
(定义 (<name> <parameter> ...)
  <body>)
```

定义函数。

定义函数等价于定义值为 lambda 的变量。

```meta-lisp
(定义 (add1 x)
  (整数加 1 x))
```

等价于：

```meta-lisp
(定义 add1
  (函 (x)
    (整数加 1 x)))
```

函数体 `<body>` 可以是多个表达式：

```meta-lisp
(定义 (f x)
  (令 ((y (整数加 x 1)))
    (整数乘 y 2)))
```

# 类型

## 原子类型

| 类型        | 说明   | 例子                          |
|-------------|--------|-------------------------------|
| `整数型`     | 整数   | `42` `-1`                     |
| `浮点型`   | 浮点数 | `3.14` `-2.5`                 |
| `文本型`  | 文本 | `"hello"`                     |
| `符号型`  | 符号   | `'foo`                        |
| `关键字型` | 关键字 | `:key`                        |
| `真假型`    | 真假值 | `真` `假`                |
| `空型`    | 空值   | `空`                        |
| `文件型`    | 文件   | `(打开输入文件 "abc.txt")` |

## 容器类型

| 类型           | 说明                       |
|----------------|----------------------------|
| `(列表型 E)`   | 元素类型为 `E` 的列表      |
| `(集合型 E)`    | 元素类型为 `E` 的集合      |
| `(散列型 K V)` | 键为 `K` 值为 `V` 的哈希表 |

## (->)

```meta-lisp
(-> <arg-type> ... <ret-type>)
```

函数类型。

接收 `<arg-type>` 参数，返回 `<ret-type>`。

例如：

```meta-lisp
(-> 整数型 整数型)
(-> 整数型 整数型 整数型)
(-> 文本型 真假型)
```

## (claim)

```meta-lisp
(声明 <name> <type>)
```

声称一个名字的类型。

编译器会从 `(定义)` 的 `<body>` 推导出类型，
然后检查是否与 `(声明)` 的类型一致。

```meta-lisp
(声明 add1 (-> 整数型 整数型))
(定义 (add1 x) (整数加 x 1))

(声明 answer 整数型)
(定义 answer 42)
```

## (admit)

```meta-lisp
(承认 <name> <type>)
```

承认名字的类型。

与 `(声明)` 类似，但是编译器不会检查 `(定义)` 的 `<body>`。

```meta-lisp
(承认 作point (-> 浮点型 浮点型 point-t))
(定义 (作point x y)
  (@列表 'make-point x y))
```

## (the)

```meta-lisp
(标注 <type> <exp>)
```

显式标注 `<exp>` 的类型。

编译器会检查 `<exp>` 的实际类型是否匹配。可用于澄清代码意图或帮助类型推断。

```meta-lisp
(标注 整数型 42)
(标注 (-> 整数型 整数型)
  (函 (x)
    (整数加 x 1)))
```

## (polymorphic)

```meta-lisp
(多态 (<type-parameter> ...)
  <type>)
```

包含类型变量的类型。

类型变量通常用单个大写字母表示，在 `<type>` 中可以被引用。
用于 `声明` 中声称多态函数。

```meta-lisp
(声明 恒等函数 (多态 (A) (-> A A)))

(声明 首 (多态 (E) (-> (列表型 E) E)))
(声明 余 (多态 (E) (-> (列表型 E) (列表型 E))))
(声明 添 (多态 (E) (-> E (列表型 E) (列表型 E))))
```


# 条件

## (if)

```meta-lisp
(若 <condition>
  <consequent>
  <alternative>)
```

条件分支。

`<condition>` 被求值。
如果为真，求值 `<consequent>` 并返回。
否则求值 `<alternative>` 并返回。

```meta-lisp
(定义 (abs x)
  (若 (整数小于 x 0)
    (整数负 x)
    x))
```

## (when)

```meta-lisp
(当 <condition>
  <body>)
```

条件为真时执行，用于副作用。

`<condition>` 为真时求值 `<body>`，否则跳过。
`<body>` 中可以写多个表达式。
`(当)` 表达式的返回值总是 `空`。

```meta-lisp
(当 debug
  (打印 "debug mode")
  (换行))
```

## (unless)

```meta-lisp
(除非 <condition>
  <body>)
```

条件为假时执行，用于副作用。

`<condition>` 为假时求值 `<body>`，否则跳过。
`<body>` 中可以写多个表达式。
`(除非)` 表达式的返回值总是 `空`。

```meta-lisp
(除非 (相等 x 0)
  (打印 (整数除 1 x))
  (换行))
```

## (cond)

```meta-lisp
(若则
  (<question> <answer>)
  ...)
```

多分支条件。

依次求值每个 `<question>`。
第一个为真的分支的 `<answer>` 被求值并返回。
末尾的 `<question>` 可以写 `否则` 作为默认分支。

```meta-lisp
(定义 (classify x)
  (若则
   ((整数为正 x) "positive")
   ((int为负 x) "negative")
   (否则 "zero")))
```

## (and)

```meta-lisp
(且 <exp> ...)
```

短路与。

从左到右求值。遇到第一个假值就停止并返回该值。全真时返回最后一个值。

```meta-lisp
(且 (为整数 x) (整数为正 x))
```

零个参数时返回 `真`。

## (or)

```meta-lisp
(或 <exp> ...)
```

短路或。

从左到右求值。遇到第一个真值就停止并返回该值。全假时返回最后一个值。

```meta-lisp
(或 (相等 x 0) (相等 x 1))
```

零个参数时返回 `假`。

# 顺序与绑定

## (begin)

```meta-lisp
(循序 <body>)
```

顺序执行。

`<body>` 可以是多个表达式 `<exp> ...`，
依次求值，返回最后一个表达式的值。
前面的表达式通常是为了副作用。

```meta-lisp
(循序
  (打印行 "step 1")
  (打印行 "step 2")
  42)  ;; => 42
```

`(函)` 和 `(定义)` 中的 `<body>` 函数体，
都类似于 `(循序)` 的 `<body>`。

```meta-lisp
(定义 (f x)
  (令 ((y (整数加 x 1)))
    (整数乘 y 2)))
```

## (let)

```meta-lisp
(令 ((<name> <exp>)
      ...)
  <body>)
```

顺序局部变量绑定。

每个 `<exp>` 可以引用前面绑定的名字。

```meta-lisp
(令 ((x 1))
  (整数加 x 1))  ;; => 2

(令 ((x 1)
      (y 2))
  (整数加 x y))  ;; => 3

(令 ((x 1)
      (y (整数加 x 1)))
  (整数加 x y))  ;; => 3
```

## (letrec)

```meta-lisp
(递归令 ((<name> <exp>)
         ...)
  <body>)
```

类似 `(令)`，但是允许递归与互相递归。

所有 `<exp>` 可以引用所有 `<name>`。

互相递归的例子：

```meta-lisp
(递归令 ((为偶数
          (函 (n)
            (若 (相等 n 0)
              真
              (为奇数 (整数减 n 1)))))
         (为奇数
          (函 (n)
            (若 (相等 n 0)
              假
              (为偶数 (整数减 n 1))))))
  (断言 (为偶数 4)))
```

顺序依赖的例子：

```meta-lisp
(递归令 ((a 1)
         (b (整数加 a 1)))
  b)  ;; => 2
```

## local (define)

```meta-lisp
(定义 (<name> <parameter> ...) <body>)
(定义 <name> <exp>)
```

`<body>` 中的局部可递归变量绑定。

允许 `(定义)` 在 `<body>` 中使用。
用来代替嵌套的 `(递归令)`，以减少缩进。

互相递归的例子（与 `(递归令)` 的例子等价）：

```meta-lisp
(循序
  (定义 (为偶数 n)
    (若 (相等 n 0)
      真
      (为奇数 (整数减 n 1))))
  (定义 (为奇数 n)
    (若 (相等 n 0)
      假
      (为偶数 (整数减 n 1))))
  (为偶数 4))
```

顺序依赖的例子：

```meta-lisp
(循序
  (定义 a 1)
  (定义 b (整数加 a 1))
  b)  ;; => 2
```

`(令)` 与 `(定义)` 可以混合使用：

```meta-lisp
(循序
  (令 ((one 1))
    (定义 a one)
    (定义 b (整数加 a one))
    b))  ;; => 2
```

# 函数组合

## (pipe)

```meta-lisp
(管道 <init> <step> ...)
```

管道。

将 `<init>` 传入第一个 `<step>`，结果传入第二个 `<step>`，以此类推。

```meta-lisp
(管道 5 add1 double)        ;; => 12
(管道 2 add1 double square) ;; => 36
```

等价于：

```meta-lisp
(double (add1 5))           ;; => 12
(square (double (add1 2)))  ;;  => 36
```

## (chain)

```meta-lisp
(串联 <step> ...)
```

管道式函数复合。

与 `(管道)` 的区别是 `(串联)` 不传入初始值，而是返回一个函数。

```meta-lisp
(串联 add1 double)
(串联 add1 double square)
```

等价于：

```meta-lisp
(函 (x) (管道 x add1 double))
(函 (x) (管道 x add1 double square))
```

等价于：

```meta-lisp
(函 (x) (double (add1 x)))
(函 (x) (square (double (add1 x))))
```

## (compose)

```meta-lisp
(复合 <step> ...)
```

数学式函数组合。

与 `(串联)` 的复合方向相反。

```meta-lisp
(复合 add1 double)
(复合 add1 double square)
```

等价于：

```meta-lisp
(函 (x) (add1 (double x)))
(函 (x) (add1 (double (square x))))
```

# 代数数据类型

**代数数据类型**（Algebraic data type）是 meta-lisp 的核心数据类型。

meta-lisp 提供了从**显式**（explicit）到便捷的多种语法来定义数据类型：

| 语法                      | 用途                         |
|---------------------------|------------------------------|
| `(定义代数类型)` | 多构造器，所有名字由你指定   |
| `(定义记录类型)`    | 单构造器，所有名字由你指定   |
| `(定义结构*)`        | 单构造器，可指定构造器名字   |
| `(定义结构)`         | 单构造器，按约定生成所有名字 |
| `(定义枚举)`           | 多构造器，按约定生成所有名字 |

所有便捷语法最终都展开为 `(定义代数类型)`。
其中最常用的是 `(定义枚举)` 和 `(定义结构)`。

## (define-algebraic-type)

```meta-lisp
(定义代数类型 <type-name>
  ((<constructor-name> (<field-name> <type>) ...)
   <predicate-name>
   (<field-name> <accessor-name> <modifier-name>)
   ...)
  ...)

(定义代数类型 (<type-name> <type-parameter> ...)
  ((<constructor-name> (<field-name> <type>) ...)
   <predicate-name>
   (<field-name> <accessor-name> <modifier-name>)
   ...)
  ...)
```

**代数数据类型**（algebraic data type）是构建复合数据结构的核心机制。

`(定义代数类型)` 是最基础的语法形式，其中所有名字由你显式指定。

只有 `<modifier-name>` 是可选的。
如果不写，这个 field 的引用就是不可修改的。

例如：

```meta-lisp
(定义代数类型 point-t
  ((作point (x 浮点型) (y 浮点型))
   为point
   (x point-x point-put-x之)
   (y point-y point-put-y之)))
```

将会生成具有下列类型的函数：

```meta-lisp
(声明 作point (-> 浮点型 浮点型 point-t))
(声明 为point (-> point-t 真假型))
(声明 point-x (-> point-t 浮点型))
(声明 point-y (-> point-t 浮点型))
(声明 point-put-x之 (-> 浮点型 point-t point-t))
(声明 point-put-y之 (-> 浮点型 point-t point-t))
```

使用举例：

```meta-lisp
(定义 p (作point 1.0 2.0))
(为point p)      ;; => true
(point-x p)     ;; => 1.0
(point-put-x之 p 3.0)
(point-x p)     ;; => 3.0
```

对于只有单一构造器的代数类型而言，
谓词 `为point` 是多余的，没有意义的。
只有代数类型有多个构造器时，
所生成的谓词才有意义。

`(定义代数类型)` 所定义的类型可以带有类型参数。

例如：

```meta-lisp
(定义代数类型 (my-list-t E)
  ((nil)
   为nil)
  ((li (head E) (tail (my-list-t E)))
   为li
   (head li-head li-put-head之)
   (tail li-tail li-put-tail之)))
```

将会生成具有下列类型的函数：

```meta-lisp
(声明 nil (多态 (E) (-> (my-list-t E))))
(声明 为nil (多态 (E) (-> (my-list-t E) 真假型)))
(声明 li (多态 (E) (-> E (my-list-t E) (my-list-t E))))
(声明 为li (多态 (E) (-> (my-list-t E) 真假型)))
(声明 li-head (多态 (E) (-> (my-list-t E) E)))
(声明 li-tail (多态 (E) (-> (my-list-t E) (my-list-t E))))
(声明 li-put-head之 (多态 (E) (-> E (my-list-t E) (my-list-t E))))
(声明 li-put-tail之 (多态 (E) (-> (my-list-t E) (my-list-t E) (my-list-t E))))
```

## (define-record-type)

```meta-lisp
(定义记录类型 <type-name>
  (<constructor-name> (<field-name> <type>) ...)
  <predicate-name>
  (<field-name> <accessor-name> <modifier-name>)
  ...)

(定义记录类型 (<type-name> <type-parameter> ...)
  (<constructor-name> (<field-name> <type>) ...)
  <predicate-name>
  (<field-name> <accessor-name> <modifier-name>)
  ...)
```

与 `(定义代数类型)` 类似，但是只有一个构造器。

```meta-lisp
(定义记录类型 point-t
  (作point (x 浮点型) (y 浮点型))
  为point
  (x point-x point-put-x之)
  (y point-y point-put-y之))
```

等价于：

```meta-lisp
(定义代数类型 point-t
  ((作point (x 浮点型) (y 浮点型))
   为point
   (x point-x point-put-x之)
   (y point-y point-put-y之)))
```

`(定义记录类型)` 这个语法来自 scheme，
起源于 scheme 48 这个 scheme 方言。

我们给这个语法加上了 `<field-name>` 的类型声明，
即 `(<field-name> <type>)`。

`(定义代数类型)` 模仿 `(定义记录类型)`，
进一步支持了多个构造器。

## (define-enum)

```meta-lisp
(定义枚举 <type-name>
  (<constructor-name> (<field-name> <type>) ...)
  ...)

(定义枚举 (<type-name> <type-parameter> ...)
  (<constructor-name> (<field-name> <type>) ...)
  ...)
```

定义多个构造器的代数数据类型。
每个构造器按照约定生成谓词、访问器和修改器的名字。

```meta-lisp
(定义枚举 exp-t
  (var-exp (name 符号型))
  (apply-exp (target exp-t) (arg exp-t))
  (lambda-exp (parameter 符号型) (body exp-t)))
```

等价于：

```meta-lisp
(定义代数类型 exp-t
  ((var-exp (name 符号型))
   为var-exp
   (name var-exp-name var-exp-put-name之))
  ((apply-exp (target exp-t) (arg exp-t))
   为apply-exp
   (target apply-exp-target apply-exp-put-target之)
   (arg apply-exp-arg apply-exp-put-arg之))
  ((lambda-exp (parameter 符号型) (body exp-t))
   为lambda-exp
   (parameter lambda-exp-parameter lambda-exp-put-parameter之)
   (body lambda-exp-body lambda-exp-put-body之)))
```

对于某个给定的 `<constructor-name>` 生成其名字的规则如下：

- `<predicate-name>` = `为<constructor-name>` -- `为var-exp`
- `<accessor-name>` = `<constructor-name>-<field-name>` -- `var-exp-name`
- `<modifier-name>` = `<constructor-name>-put-<field-name>!` -- `var-exp-put-name之`

## (define-struct)

```meta-lisp
(定义结构 <type-name>
  (<field-name> <type>)
  ...)

(定义结构 (<type-name> <type-parameter> ...)
  (<field-name> <type>)
  ...)
```

定义单构造器结构体。
`<type-name>` 类型名必须以 `-t` 结尾，
格式为 `<base-name>-t`。
其中 `<base-name>` 将被用于生成其他名字。

```meta-lisp
(定义结构 point-t
  (x 浮点型)
  (y 浮点型))
```

等价于：

```meta-lisp
(定义代数类型 point-t
  ((作point (x 浮点型) (y 浮点型))
   为point
   (x point-x point-put-x之)
   (y point-y point-put-y之)))
```

对于某个给定的 `<type-name>` 生成其名字的规则如下：

- `<type-name>` = `<base-name>-t` -- `point-t`
- `<predicate-name>` = `为<base-name>` -- `为point`
- `<constructor-name>` = `make-<base-name>` -- `作point`
- `<accessor-name>` = `<base-name>-<field-name>` -- `point-x`
- `<modifier-name>` = `<base-name>-put-<field-name>!` -- `point-put-x之`

<a name="define-struct-star"></a>
## (define-struct*)

```meta-lisp
(定义结构* <type-name>
  (<constructor-name>
   (<field-name> <type>)
   ...))

(定义结构* (<type-name> <type-parameter> ...)
  (<constructor-name>
   (<field-name> <type>)
   ...))
```


与 `(定义结构)` 类似，但是 `<constructor-name>` 由用户给出。

```meta-lisp
(定义结构* point-t
  (作point
   (x 浮点型)
   (y 浮点型)))
```

等价于：

```meta-lisp
(定义结构 point-t
  (x 浮点型)
  (y 浮点型))
```

之所以给 `(定义结构)` 增加这个变体，
是因为有时需要把 `make-<base-name>` 保留给更简单的构造器。

```meta-lisp
(定义结构* package-t
  (作package
   (root-directory 文本型)
   (config package-config-t)
   (fragments (散列型 文本型 fragment-t))))

(定义 (empty-package root-directory config)
  (作package root-directory config (作散列)))
```

## (match)

```meta-lisp
(匹配 <target>
  (<pattern> <body>)
  ...)
```

用模式匹配的方式解构代数数据类型。

```meta-lisp
(定义枚举 exp-t
  (var-exp (name 符号型))
  (apply-exp (target exp-t) (arg exp-t))
  (lambda-exp (parameter 符号型) (body exp-t)))

(定义 (evaluate exp env)
  (匹配 exp
    ((var-exp name)
     (env-lookup-of-fail name env))
    ((apply-exp target arg)
     (apply (evaluate target env) (evaluate arg env)))
    ((lambda-exp parameter body)
     (closure-value env parameter body))))
```

# 不透明类型

## (define-opaque-type)

```meta-lisp
(定义黑盒类型 <type-name> <representation-type>
  (<interface-name> <interface-type>)
  ...)

(定义黑盒类型 (<type-name> <type-parameter> ...) <representation-type>
  (<interface-name> <interface-type>)
  ...)
```

定义不透明类型，隐藏内部表示。

例如 builtin 中的 `匣子型`，内部表示为 `(列表型 E)`：

```meta-lisp
(定义黑盒类型 (匣子型 E) (列表型 E)
  (作匣子 (-> (匣子型 E)))
  (匣子为空 (-> (匣子型 E) 真假型))
  (匣子置之 (-> E (匣子型 E) (匣子型 E)))
  (匣子取或有 (-> (匣子型 E) (或有型 E))))
```

在实现接口函数的时候，等价于声明了：

```meta-lisp
(声明 作匣子 (多态 (E) (-> (列表型 E))))
(声明 匣子为空 (多态 (E) (-> (列表型 E) 真假型)))
(声明 匣子置之 (多态 (E) (-> E (列表型 E) (列表型 E))))
(声明 匣子取或有 (多态 (E) (-> (列表型 E) (或有型 E))))
```

因此接口函数内部可以使用 list API 来实现：

```meta-lisp
(定义 (作匣子) (作列表))

(定义 (匣子置之 value box)
  (若 (匣子为空 box)
    (列表末入之 value box)
    (列表置之 0 value box)))
```

在使用接口函数的时候，等价于声明了：

```meta-lisp
(声明 作匣子 (多态 (E) (-> (匣子型 E))))
(声明 匣子为空 (多态 (E) (-> (匣子型 E) 真假型)))
(声明 匣子置之 (多态 (E) (-> E (匣子型 E) (匣子型 E))))
(声明 匣子取或有 (多态 (E) (-> (匣子型 E) (或有型 E))))
```

外部代码只能通过接口函数来操作 `匣子型`：

```meta-lisp
(声明 匣子取 (多态 (E) (-> (匣子型 E) E)))
(定义 (匣子取 box)
  (匹配 (匣子取或有 box)
    ((有 value) value)
    ((无) (错误 "box is empty"))))
```

# 模块

一个文件夹可以被视为一个**项目**（package），
项目中的所有 `.meta` 文件，都被视为属于这个项目。

一个项目中可以有多个**模块**（module）。

模块系统与文件系统解耦，存放模块的路径和文件名并不重要。
同一模块的代码，可以拆分到不同文件中。

## (module)

```meta-lisp
(模块 <module-name>)
```

声明当前模块。

每个 `.meta` 文件必带有一个模块声明，一般放在开头。

在同一个项目中，可以通过 `<module-name>/<name>` 引用别的模块中的名字。

同一个模块中的函数，就算写在不同的文件中，也可以相互递归。

`even.meta`:

```meta-lisp
(模块 example)

(定义 (为偶数 n)
  (若 (相等 n 0)
    真
    (为奇数 (整数减 n 1))))
```

`odd.meta`:

```meta-lisp
(模块 example)

(定义 (为奇数 n)
  (若 (相等 n 0)
    假
    (为偶数 (整数减 n 1))))
```

## (import)

```meta-lisp
(导入 <module-name> <name> ...)
```

从其他模块导入指定名字。

导入后可以直接使用，不需要限定前缀。

```meta-lisp
(导入 math pi circumference)
```

之后，

```meta-lisp
math/pi
math/circumference
```

可简写为：

```meta-lisp
pi
circumference
```

## (import-as)

```meta-lisp
(导入为 <module-name> <prefix>)
```

导入模块并修改前缀。

`<module-name>/<name>` 改为 `<prefix>/<name>`。

```meta-lisp
(导入为 meta m)
```

之后，

```meta-lisp
meta/exp-t
```

可简写为：

```meta-lisp
m/exp-t
```

## (import-all)

```meta-lisp
(全导入 <module-name>)
```

导入模块中所有名字。

使得所有名字都可以不用前缀就能引用。

如果当前模块已经有重复的名字，
就略过这个名字不导入。

因此，不带前缀的引用，还是会引用到当前模块自己的名字。
或者说本地的定义，可以覆盖 `(全导入)` 所引入的定义。

## (private)

```meta-lisp
(私有 <name> ...)
```

将名字标记为私有。

被标记为私有的名字不能被其他模块引用。

```meta-lisp
(模块 serial-number)

(私有 serial-number-hash)
(定义 serial-number-hash (作散列))
```

# 测试

## (define-test)

```meta-lisp
(定义测试 <test-name> <body>)
```

定义测试。

`<body>` 中可以包含多个断言。

```meta-lisp
(声明 add1 (-> 整数型 整数型))
(定义 (add1 x) (整数加 x 1))

(定义测试 add1-test
  (断言相等 2 (add1 1))
  (断言相等 0 (add1 -1)))
```

支持以下断言：

- `(断言 x)` -- 断言 `x` 为 `真`。
- `(断言非 x)` -- 断言 `x` 为 `假`。
- `(断言相等 lhs rhs)` -- 断言 `lhs` 与 `rhs` 相等（使用 `相等` 比较）。
- `(断言不等 lhs rhs)` -- 断言 `lhs` 与 `rhs` 不相等。

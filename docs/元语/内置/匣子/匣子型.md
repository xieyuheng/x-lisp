类型型

# 描述

匣子类型构造器。内部表示为 `(列表型 甲)`。

# 定义

```meta-lisp
(定义黑盒类型 (匣子型 甲) (列表型 甲)
  (作匣子 (-> (匣子型 甲)))
  (匣子为空 (-> (匣子型 甲) 真假型))
  (匣子存 (-> 甲 (匣子型 甲) (匣子型 甲)))
  (匣子取或有 (-> (匣子型 甲) (或有型 甲))))
```

---
title: 解析结森
---

# 类型

```meta-lisp
(-> 文本型 结森型)
```

# 描述

将 JSON 文本解析为 `结森型` 值。

# 例子

```meta-lisp
(解析结森 "null")            ;; => (空结森)
(解析结森 "true")            ;; => (真假结森 真)
(解析结森 "42")              ;; => (数字结森 42.0)
(解析结森 "\"hello\"")       ;; => (文本结森 "hello")
(解析结森 "[1, 2, 3]")       ;; => (数组结森 (@list (数字结森 1.0) ...))
(解析结森 "{\"x\": 1}")      ;; => (对象结森 (@散列 "x" (数字结森 1.0)))
```

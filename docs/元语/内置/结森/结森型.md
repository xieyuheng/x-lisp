# 类型

```meta-lisp
类型型
```

# 描述

JSON 值类型。表示解析后的 JSON 值。

# 定义

```meta-lisp
(定义枚举 结森型
  (空结森)
  (真假结森 (值 真假型))
  (数字结森 (值 浮点型))
  (文本结森 (值 文本型))
  (数组结森 (元素 (列表型 结森型)))
  (对象结森 (条目 (散列型 文本型 结森型))))
```

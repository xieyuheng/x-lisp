---
title: 列表映射索引拼接
---

# 类型

```meta-lisp
(泛型 (甲 乙) (-> (-> 整数型 甲 (列表型 乙)) (列表型 甲) (列表型 乙)))
```

# 描述

对列表中的每个元素应用带索引的函数，将结果列表扁平化一层。

# 例子

```meta-lisp
(列表映射索引拼接 (函 (索引 元素) (@列表 索引 元素)) (@列表 10 20 30))
;; => (@list 0 10 1 20 2 30)

(列表映射索引拼接 (函 (索引 元素) (@列表 (作序对 索引 元素) (作序对 索引 元素))) (@列表 'a 'b 'c))
;; => (@list (作序对 0 'a) (作序对 0 'a) (作序对 1 'b) (作序对 1 'b) (作序对 2 'c) (作序对 2 'c))
```

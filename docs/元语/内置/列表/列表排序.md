---
title: 列表排序
---

# 类型

```meta-lisp
(泛型 (甲) (-> (-> 甲 甲 整数型) (列表型 甲) (列表型 甲)))
```

# 描述

使用比较函数对列表原地排序。返回原列表。

# 例子

```meta-lisp
;; 整数
(列表排序 整数升序比较 (@列表 3 1 2))   ;; => (@list 1 2 3)
(列表排序 整数降序比较 (@列表 3 1 2))  ;; => (@list 3 2 1)

;; 浮点
(列表排序 浮点升序比较 (@列表 3.0 1.0 2.0))   ;; => (@list 1.0 2.0 3.0)
(列表排序 浮点降序比较 (@列表 3.0 1.0 2.0))  ;; => (@list 3.0 2.0 1.0)

;; 文本
(列表排序 文本字典序比较 (@列表 "c" "a" "b"))     ;; => (@list "a" "b" "c")
```

---
title: 当前完整命令行
---

# 类型

```meta-lisp
(-> (列表型 文本型))
```

# 描述

获取传递给 xvm 可执行文件的完整命令行参数（包括可执行文件名和子命令）。

例如，给定调用：

```
xvm run program.x86.exe -- check --verbose
```

`(当前完整命令行)` 返回
`["xvm" "run" "program.x86.exe" "--" "check" "--verbose"]`。

# 例子

```meta-lisp
(当前完整命令行)
;; => (@list "xvm" "run" "program.x86.exe" "--" "check" "--verbose")
```

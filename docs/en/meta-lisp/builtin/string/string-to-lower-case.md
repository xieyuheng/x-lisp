---
title: string-to-lower-case
---

# Type

```scheme
(-> string-t string-t)
```

# Description

Convert all letters in a string to lower case.

# Examples

```scheme
(string-to-lower-case "HELLO")  ;; => "hello"
(string-to-lower-case "Hello")  ;; => "hello"
(string-to-lower-case "123")    ;; => "123"
```

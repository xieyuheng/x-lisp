---
title: string-to-upper-case
---

# Type

```meta-lisp
(-> string-t string-t)
```

# Description

Convert all letters in a string to upper case.

# Examples

```meta-lisp
(string-to-upper-case "hello")  ;; => "HELLO"
(string-to-upper-case "Hello")  ;; => "HELLO"
(string-to-upper-case "123")    ;; => "123"
```

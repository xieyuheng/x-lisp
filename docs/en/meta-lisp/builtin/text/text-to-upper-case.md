---
title: text-to-upper-case
---

# Type

```meta-lisp
(-> text-t text-t)
```

# Description

Convert all letters in a text to upper case.

# Examples

```meta-lisp
(text-to-upper-case "hello")  ;; => "HELLO"
(text-to-upper-case "Hello")  ;; => "HELLO"
(text-to-upper-case "123")    ;; => "123"
```

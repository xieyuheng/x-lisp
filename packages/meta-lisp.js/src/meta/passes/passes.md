# 引子

编译器在于弥合语言之间的差异。

这里的工序（pass）在于弥合 meta-lisp 和 basic-lisp 之间的差异。

- meta-lisp 是带有 HM 类型的系统和模式匹配的语言。
- basic-lisp 是 SSA 中间语言。
